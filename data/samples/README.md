# Demonstration data boundary

Phase 1 seeds only the five canonical application workstation definitions (720-second default).
It does not seed materials, rack models, BOM quantities, demand or inventory.

The supplied workbook/JSON archive contains synthetic demonstrations. Import and alias review
belong to Phase 2. Synthetic material records may be stored as catalog data, but database
constraints and inventory services reject them in operational balances, events and reservations.
Simulation inventory belongs exclusively to scenario/run JSON and future run-scoped projections.
